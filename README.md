<details>
<summary><b>🎬 Hub 1: Dynamic Motion & Animation (GSAP & Lottie)</b></summary>
<br>

This capability hub directs high-performance vector rendering, smooth scroll-driven orchestration, timeline sequencing, and physics-based fluid micro-interactions.

### Configured Workspace Skills
- `motion-design`
- `dotlottie-web`
- `gsap-core`
- `gsap-timeline`
- `gsap-scrolltrigger`
- `gsap-plugins`
- `gsap-react`
- `gsap-performance`
- `gsap-utils`

### Mapped Developer Capabilities

* **Engine Timing & Easing Control**: Employs mathematically modeled animation curves (*Playful*, *Premium*, *Corporate*, and *Energetic*) and coordinates complex staggers under strict delay budgets (<500ms).
* **Multi-Element Choreography**: Enforces the **1/3 Rule** (max 1/3 element density in active motion; max 1/3 screen distance without keyframes) to maintain visual pacing.
* **Canvas Thread Offloading**: Integrates `DotLottieWorker` and `DotLottieWorkerReact` to render animations inside dedicated Web Workers, preserving 120Hz frame rates on the main thread.
* **Dynamic runtime slots**: Mutates stroke widths, fill states, vector path coordinates, and themes dynamically based on dotLottie 2.0 specs.
* **ScrollTrigger Bindings**: Hooks complex hardware-accelerated animations (`x`, `y`, `scale` via GPU) directly to scroll scrubbing, pinning, and entry offsets.

</details>
